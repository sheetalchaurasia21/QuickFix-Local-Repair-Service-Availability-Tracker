# 🔧 QuickFix – Local Repair Service Platform

QuickFix is a MERN stack web application that connects users with nearby service providers (like electricians, plumbers, etc.) based on availability and location.

---

## 🚀 Features

### 👤 Customer
- Search services by location
- View service providers
- Book services instantly
- Track bookings

### 🛠 Provider
- Register and list services
- Set availability status
- Manage bookings

### 🛡 Admin
- Manage users and providers
- Monitor bookings
- View analytics

---

## 🖥️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
